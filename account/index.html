Account maken

Je hebt een uitnodigingscode nodig. Een e-mailadres vragen we niet: er is dus ook geen "wachtwoord vergeten"-mail. Je krijgt in plaats daarvan één herstelcode.

Wat er met je gegevens gebeurt

  • Je berekeningen worden in je browser versleuteld met een sleutel uit je wachtwoord. De server bewaart alleen onleesbare blokken, en weet niet eens bij welke rekenhulp ze horen.

  • Je wachtwoord wordt nooit verstuurd. Je gebruikersnaam staat alleen als onherkenbare code in de database. Er worden geen IP-adressen bewaard.

  • De keerzijde: niemand kan je wachtwoord herstellen, ook de beheerder niet. Zonder wachtwoord én zonder herstelcode zijn je berekeningen weg.

  • Je kunt je account en alles wat erbij hoort op elk moment zelf verwijderen.

?
Wachtwoord kwijt

Met je herstelcode stel je een nieuw wachtwoord in. Je berekeningen blijven bewaard. Twee-factor gaat uit en je krijgt een nieuwe herstelcode.

!
Bewaar je herstelcode

Dit is je herstelcode. Je ziet hem maar één keer. Schrijf hem op of zet hem in je wachtwoordmanager.

Vergeet je je wachtwoord, dan is deze code de enige manier om bij je berekeningen te komen. Wie de code heeft, kan je account overnemen: bewaar hem dus niet naast je wachtwoord.

Dit verwijdert je account en al je bewaarde berekeningen, direct en definitief. Download ze eerst als je ze wilt houden.
